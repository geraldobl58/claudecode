## Project

Arcade Vault — a platform for playing games online and competing for the highest score (see README.md, in Spanish). The codebase is currently the unmodified `create-next-app` scaffold (App Router); no game features, routes, or components exist yet beyond `src/app/page.tsx` and `src/app/layout.tsx`.

## Critical: this is not the Next.js you know

Per AGENTS.md, this project pins `next@16.3.4` / `react@19.2.8`, versions newer than this model's training data, with breaking API/convention/file-structure changes. **Before writing any Next.js code, read the relevant guide under `node_modules/next/dist/docs/`** (App Router docs live in `01-app/`, Pages Router in `02-pages/`) rather than relying on prior knowledge, and heed any deprecation notices found there. Note the `LayoutProps<"/">` generic already used in `src/app/layout.tsx:20` — a typed-routes convention introduced in this version, not present in older Next.js.

The `# This is NOT the Next.js you know` block in AGENTS.md is regenerated by `next dev` on every run (`node_modules/next/dist/server/lib/generate-agent-files.js`). It's expected to show as a diff; commit it along with real work rather than trying to strip it.

## Commands

- `npm run dev` — start the dev server (Turbopack by default in this Next.js version)
- `npm run build` — production build
- `npm run start` — run the production build
- `npm run lint` — ESLint via the flat config in `eslint.config.mjs` (`eslint-config-next` core-web-vitals + typescript configs)

There is no test runner configured in this repository yet.

## Architecture

- App Router under `src/app/`, with the `@/*` path alias mapped to `src/*` (tsconfig.json).
- Styling is Tailwind CSS v4 via the CSS-first `@import "tailwindcss"` + `@theme inline` approach in `src/app/globals.css` (no `tailwind.config.js` — theme tokens are defined directly in CSS).
- Fonts: `next/font/google` (Geist Sans/Mono) wired into CSS variables and applied on `<html>` in `src/app/layout.tsx`.
- TypeScript strict mode is on.
